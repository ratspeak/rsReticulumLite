# Security

Report suspected vulnerabilities privately to
[mail@ratspeak.org](mailto:mail@ratspeak.org), or use
[GitHub private reporting](https://github.com/ratspeak/rsReticulumLite/security/advisories/new)
when available. Do not open a public issue.

Include the affected commit, target/profile and a minimal reproduction.
Use test identities; do not include real private keys or personal data.
